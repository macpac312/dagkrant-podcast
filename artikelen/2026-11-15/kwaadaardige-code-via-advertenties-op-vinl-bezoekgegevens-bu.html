Kwaadaardige code verspreid via reclame op voetbalsite VI, gegevens buitgemaakt

Voetbalnieuwssite VI.nl waarschuwt voor een "kwaadaardige code" die begin deze maand via advertenties op de website is verspreid onder bezoekers. De code kon volgens VI gegevens over websitebezoeken verzamelen en probeerde ook op bepaalde iPhone-toestellen toegang te krijgen tot persoonlijke gegevens.

Volgens VI zijn er gegevens over websitebezoeken buitgemaakt, zonder dat bezoekers daarvoor iets hadden aangeklikt. Het gaat onder meer om IP-adressen, bezochte pagina's, taalinstellingen en informatie over het besturingssysteem.

Het is niet vastgesteld of er privégegevens zijn buitgemaakt, meldt VI. "Een onbevoegde derde heeft zich toegang verschaft tot het beheersysteem en daarin ongeautoriseerde wijzigingen aangebracht.

Daardoor kon kwaadaardige code worden toegevoegd aan een advertentietag die onder meer op VI.nl wordt gebruikt", schrijf VI op zijn website. VI zegt dat de code inmiddels is verwijderd en dat de kwetsbaarheid in het advertentiesysteem is verholpen.

De voetbalsite onderzoekt de mogelijke gevolgen. De code was gericht op bepaalde iPhone-modellen die niet de nieuwste beveiligingsupdates hebben geïnstalleerd, zoals de Phone XS, XR, 6s, 7 en SE van de eerste generatie.

VI adviseert gebruikers van de telefoons die tussen 1 en 3 november en op 11 november de website hebben bezocht maatregelen te nemen. Op de website van VI staat daarvoor een stappenplan.
