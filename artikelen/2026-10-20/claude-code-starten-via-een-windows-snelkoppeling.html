Start Claude Code via een Windows-snelkoppeling met claude -p. Lees wat de opties doen, welke Windows- en accountvereisten gelden en hoe gegevens worden verwerkt.

Met claude -p kan een Windows-snelkoppeling Claude Code starten zonder de desktopinterface te openen. De opdracht draait in niet-interactieve modus en geeft een antwoord terug; voor gebruik via Anthropic heb je wel toegang tot Claude Code en een internetverbinding nodig. Anthropic beschrijft de printmodus en de toegangs- en systeemvereisten.

Een snelkoppeling kan zo een vaste opdracht met een opgeslagen prompt starten. De PowerShell-workflow van Dibakar Ghosh bij How-To Geek, gepubliceerd op 12 oktober 2026, is een persoonlijk voorbeeld: Ghosh beschrijft een script met een apart promptbestand en snelkoppelingen voor terugkerende taken. How-To Geek publiceerde het script en de exacte doelregel voor de snelkoppeling niet, dus die specifieke opzet is niet rechtstreeks uit het artikel over te nemen. Ghoshs beschrijving

Wat de opdrachtopties doen

De opties lijken soms op elkaar, maar regelen verschillende dingen. Anthropic documenteert hun werking in de CLI-referentie; de handleiding voor gebruik van Claude Code zonder interactieve sessie beschrijft -p en invoer via de standaardinvoer.

Ook tekst kan naar printmodus worden doorgegeven via de standaardinvoer (stdin). Anthropic stelt daarvoor een limiet van 10 MB. Dat is iets anders dan een afbeelding uit het klembord plakken: voor Claude Code in interactieve modus op Windows en WSL documenteert Anthropic Alt+V als sneltoets voor een klembordafbeelding. De interactieve sneltoetsen beschrijven die functie apart van de tekstinvoer voor printmodus.

Ghosh beschrijft een PowerShell-script dat ook klembordafbeeldingen verwerkt, maar de precieze overdracht naar een niet-interactieve opdracht staat niet in zijn gepubliceerde uitleg. De beschreven sneltoets Alt+V hoort bij interactieve modus; die is dus geen stap in de gedocumenteerde claude -p-invoerroute.

Werkt Claude Code op jouw Windows-pc?

Anthropic noemt Windows 10 versie 1809 of hoger en Windows Server 2019 of hoger als ondersteunde Windows-omgevingen. De algemene vereisten zijn minimaal 4 GB RAM, een x64- of ARM64-processor en een internetverbinding; PowerShell en CMD zijn ondersteunde shells. Claude Code vereist toegang via een Pro-, Max-, Team-, Enterprise- of Console-account. Het gratis claude.ai-abonnement bevat Claude Code niet. Anthropic vermeldt de platform- en accountvereisten.

Er is ook een verschil tussen Windows rechtstreeks en Windows Subsystem for Linux 2 (WSL 2). Claude Code ondersteunt sandboxing niet op native Windows; in WSL 2 is sandboxing wel beschikbaar, mits WSL 2 is ingeschakeld. Dat kan meespelen bij de keuze van de omgeving als een opdracht tools kan gebruiken.

Wat doet een snelkoppeling met klembordinvoer?

Een snelkoppeling maakt een Claude Code-aanroep niet lokaal of offline. Anthropic zegt dat Claude Code prompts en modeluitvoer via het netwerk verstuurt en dat die gegevens onderweg met TLS 1.2 of hoger worden versleuteld. Tekst die je vanuit het klembord naar Claude stuurt, gaat dus ook naar de clouddienst. Anthropic beschrijft het gegevensverkeer en de gegevensvoorwaarden.

Voor consumentenaccounts hangt het gebruik van gegevens voor toekomstige modelverbetering af van de privacyinstelling. Als een consumentengebruiker modelverbetering toestaat, noemt Anthropic een bewaartermijn van vijf jaar; als die instelling uitstaat, noemt Anthropic 30 dagen. Voor zakelijke accounts geldt standaard een bewaartermijn van 30 dagen. Zero Data Retention is alleen beschikbaar voor daarvoor in aanmerking komende accounts en wordt via het accountteam van de organisatie ingeschakeld. De voorwaarden verschillen per accounttype en instelling.

Voorbeelden van terugkerende taken

Ghosh beschrijft vier persoonlijke toepassingen: Proofreader verwerkt gekopieerde tekst, Reply maakt een antwoord op basis van een gekopieerde vraag en opgeslagen instructies, Explainer licht een foutcode of screenshot toe, en Fact Checker beoordeelt een gekopieerde bewering. Voor Explainer en Fact Checker beschrijft Ghosh ook webzoekopdrachten en resultaten in een venster. Het zijn voorbeelden van zijn eigen workflow.

De snelkoppelingen op de taakbalk zijn bovendien iets anders dan sneltoetsen binnen een interactieve Claude Code-sessie.
