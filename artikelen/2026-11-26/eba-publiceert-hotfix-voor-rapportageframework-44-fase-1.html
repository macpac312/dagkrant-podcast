​EBA publishes hotfix for the reporting framework v4.4 - Phase 1 | European Banking Authority

​The European Banking Authority (EBA) has issued a hotfix for its Reporting Framework version 4.4 - Phase 1, addressing technical issues identified following the release of the final technical package.

​The hotfix includes the addition of a missing member, amendments to a limited number of validation rules, and updates to the applicable reference date for the Pillar 3 modules. The first reporting reference date under this framework remains 31 December 2026.

​The updated technical package and related artefacts are being published several weeks ahead of the first applicable reference date to provide competent authorities and reporting institutions with sufficient time to prepare for implementation and ensure a smooth transition to the updated framework.

​A release note describing all changes introduced by the hotfix is published together with the updated taxonomy package and related documentation.

​For further details and to access the updated documentation, please visit the Reporting Framework 4.4 page.
