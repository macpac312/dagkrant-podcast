Nex-N2.6 vs Grok 4.7: Price, Context and the Score Gap

The price difference between Nex-N2.6 and Grok 4.7 is not a discount. It is a different category of purchase. At $0.12 per million input tokens and $0.40 per million output, Nex-N2.6 costs roughly one-sixteenth of Grok 4.7's $2.00 and $6.00 — and if your prompt crosses 200,000 tokens, Grok 4.7's rate doubles to $4.00 and $12.00, which takes the gap past thirty-three to one on input. So the useful question is not which model is better. Nobody, including Nex-AGI, has published a number that would let you answer that. The useful question is what you are buying with the 16x: a 500,000-token window, two years of public benchmark record, a documented tool-calling contract and a vendor with a sales desk — against a model that shipped yesterday with a price, a context length and one sentence of positioning.

The two models, stripped to what is checkable

Grok 4.7 is SpaceXAI's flagship, released 21 September 2026, and it is the settled, measured option in this matchup. Nex-N2.6 is Nex-AGI's successor to Nex-N2.5 Pro, live on the vendor's own API as of 10 November 2026, and it is the unmeasured one. Laid out dimension by dimension, with the source of each figure attached:

• Price per million tokens — Nex-N2.6 $0.12 in / $0.40 out (listing, with a 20% introductory discount implied by the struck-through $0.15 / $0.50) vs Grok 4.7 $2.00 in / $6.00 out, rising to $4.00 / $12.00 above 200K input tokens (SpaceXAI's own rate card).

• Context window — Nex-N2.6 262,144 tokens vs Grok 4.7 500,000, against which SpaceXAI allows up to 450,000 output tokens in a single call. Nex-N2.6's output ceiling is 235,929.

• Input modality — both take text and images and return text. SpaceXAI's docs also list file input on the API; Nex-N2.6's listing does not.

• Reasoning control — Nex-N2.6 is mandatory-reasoning with two settings, high and medium, defaulting to high, and no way to switch thinking off. Grok 4.7 offers low, medium, high and xhigh, defaults to high, and can be pushed to its cheapest setting when a task is mechanical.

• Base and size — Nex-N2.6 is post-trained on GLM-5.3-Flash at roughly 321 billion parameters; SpaceXAI publishes no parameter count for Grok 4.7 at all.

• Independent score — Grok 4.7 has one. Nex-N2.6 has none, on any board.

• Weights — Nex-N2.6's listing points at a Hugging Face repository that returns an authentication prompt rather than a public card. Grok 4.7 is closed, API-only, and makes no pretence otherwise.

What 500,000 tokens actually buys you

The context gap is the one place Grok 4.7's premium is easy to justify, and the place where the pricing gets least intuitive. Doubling a window from 262K to 500K is not a nice-to-have for agent work; it changes which jobs you can attempt in one call. A whole mid-sized repository's source tree, a full incident thread with logs, a long-running agent's accumulated scratchpad — all of that fits in Grok 4.7 and has to be chunked, summarised or retrieved into Nex-N2.6.

But notice where the money goes. At 200,000 input tokens the tiered rate steps in, so a request that uses the window you paid for is billed at $4.00 per million input rather than $2.00. A single 300,000-token call costs $1.20 on Grok 4.7 against roughly $0.04 on Nex-N2.6 for the equivalent prompt. The long-context capability is real and the long-context price is steep, which means the sensible architecture is different in each case: with Grok 4.7 you batch hard problems into huge calls and pay for the privilege; with Nex-N2.6 you keep calls small, rely on retrieval, and treat the window as headroom rather than a workspace.

Grok 4.7 is also the only one of the two you can route rather than merely call. It sits in the OrcaRouter catalogue at grok/grok-4.7, at SpaceXAI's own $2.00 / $6.00 with no markup, on the same key as the rest of the Grok line — Grok 4.6, 4.5, 4.3 and the 4.20 family — which matters here for a specific reason: it gives you a fallback chain inside one vendor's family without a second contract or a second SDK. Nex-N2.6 is not in our catalogue, and we will not pretend otherwise; whether that changes is Nex-AGI's call, not ours.

The score, and how to read it without being fooled

Here is where this comparison has to slow down, because the number most likely to be quoted for Grok 4.7 is a trap if you take it out of context. Artificial Analysis currently measures it at 35 on its Intelligence Index — but that is on Index version 5.0.1, which rebuilt the task set. On the previous version, 4.3.2, the same model scored 46. Both numbers are correct; they are not comparable, and any article (including ours, in September) that printed 46 alongside figures from a 5.x board was quoting across a version break. Use 35 as the current reading and do not subtract it from anything measured on the old index.

• AA-Briefcase Elo — 1,511.7 for Grok 4.7 at xhigh effort, on the long-horizon knowledge-work board, measured independently.

• Cost per Intelligence Index task — $0.26 weighted, with $0.11 of that in cache writes and $0.11 in output tokens. The cache line is the giveaway: this model is designed to be run with prompt caching on, and its effective price is a function of how much of your prompt is stable across calls.

• GDPval — 1,692.05, and HLE 49.4, both from the same independent run.

• Terminal-Bench 4.0 — 34.8, FrontierCode 2.0 — 24.0. Coding is where the flagship's margin over open-weight challengers has been thinnest all year, and these are not numbers that end an argument.

Nex-N2.6's column on that board is empty. Not weak — empty. No Artificial Analysis entry, no vendor table, no weights to run your own eval against. The only performance statement in existence is Nex-AGI's one-liner that N2.6, compared with Nex-N2.5 Pro, reduces repetitive reasoning and follows the tools available in the current environment more closely. That is a claim about tool-call discipline, made by the vendor, unreproduced, and it is the entire public performance record of this model.

Where each one is the wrong tool

Nex-N2.6 is the wrong tool when the job needs the window. If your pipeline depends on feeding a 300K-token context to a model and asking one question about it, no amount of price advantage compensates, because the call does not fit. It is also the wrong tool when you need a number before you commit — procurement, a regulated review, a bet that has to be justified in a document. A model with zero independent measurements cannot clear that bar, and it should not be argued past it.

Grok 4.7 is the wrong tool when the work is volume-shaped and cheap. Any loop that fires thousands of short calls — classifying tickets, extracting fields, grading a batch of diffs — is paying flagship rates for a task where the difference between a 35 and a hypothetical equivalent score is invisible in the output. It is also the wrong tool when you need the model to be inspectable: no weights, no config, no local run, and a hosted-only existence. If your compliance story requires a checkpoint you can hold, this model cannot be part of it.

There is a third position that is more useful than either extreme: use the cheap one where the work is repetitive and gradeable, use the expensive one where the work is long and consequential, and let a router decide which is which from the request itself rather than from a hardcoded model name. OrcaRouter's routing DSL expresses exactly that — a rule set on token count, task class or caller, evaluated per request — and it is the reason the price difference here is a routing question and not an architecture question. The 16x only matters on the traffic you actually send to the expensive side.

The decision, in one paragraph each

Pick Nex-N2.6 if you are already inside the Nex-AGI tooling ecosystem, your prompts are short, your workload is a screenshot-driven or tool-heavy agent loop where the model's supposed improvement is precisely what you need, and you can grade its output yourself on a sample of real tasks this week. At $0.12 / $0.40 the experiment is affordable, and being early on a model that turns out to be good is worth something. Go in knowing that you are running a single-endpoint dependency with no published weights and no independent score, and that a price rise — not a cut — is how this model arrived.

Pick Grok 4.7 if the work needs 500,000 tokens in one call, if a benchmark record is a requirement rather than a preference, or if you want a model that a router can fail over within a family that already has five generations in it. You will pay 16 times Nex-N2.6's rate for output, more above 200K input, and you will get the only thing that a 16x premium can honestly buy: a model whose behaviour other people have already measured. For anything that has to work on the first try, that premium is usually the cheaper line item.

The thing to watch

This matchup will look completely different within a month, and the trigger is not a price change — it is a benchmark row. If Nex-N2.6's card opens with its own tables, or an independent score lands on a public board, the comparison becomes ordinary: two models with numbers, one cheaper, one wider. If neither happens, the gap in this article stops being about capability and becomes about trust, and the 16x premium on Grok 4.7 quietly turns into the price of knowing what you are buying.
