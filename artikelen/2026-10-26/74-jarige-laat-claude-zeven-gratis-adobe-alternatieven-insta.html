Introduction

It took me half a day to install 7 free Adobe alternatives on my Linux Mint PC and get Claude to run them. The inspiration was a YouTube video claiming that "Adobe has been completely recreated for free." It showed that software replacing Photoshop, Premiere, Word, and Excel was available for free and could be operated by Claude (AI). Can I really do this at 74? I will write down everything, including the parts where I stumbled, after actually trying it. I hope this serves as a guide for others who want to try the same thing.

What is ArtCraft?

ArtCraft is a collection of free software released by an overseas development team. The source code is fully public, and it uses a license (MIT/Apache-2.0) that allows free use even for work. It runs on Windows, Mac, and Linux. The 7 programs I installed this time are as follows (as of October 20, 2026).

The biggest feature is that every piece of software is designed to be operated by text commands. That is why an AI can operate them instead of a human. I will also write about the honest current situation. Although the video introduced them as "exactly the same as Adobe," the developers themselves write that "it is still in the early prototype stage (alpha version) and cannot yet replace professional daily work." The fact that you can try them for free and that an AI can operate them is certain. Source: ArtCraft Official Page, PhotoCraft (GitHub)

Step 2: Install and log in to Claude Code

Claude Code is Claude used within the terminal. Since the Claude you talk to in a browser runs on the internet, it cannot operate software on your own computer. To have it run software on your PC, you need Claude Code. Using it requires a paid Claude plan (Pro or higher).

curl -fsSL https://claude.ai/install.sh | bash

When "Claude Code successfully installed!" appears, close the terminal and reopen it.

Create a working folder and launch Claude there.

When asked "Do you trust this folder?", use the down arrow key to select "Yes, I trust this folder" and press Enter.

Type /login in the input field and select "Claude account with subscription".

A browser will open; log in. If it says "You are ready to use Claude Code," you have succeeded.

At first, I launched it in the entire home folder. If you grant permission there, Claude will be able to access everything, including photos and documents. It is safer to separate a working folder.

On the confirmation screen, the item marked with "❯" is selected. At first, I pressed Enter while "No, exit" was still marked, and Claude exited.

If "Not logged in" appears in the bottom right even after launching, you cannot use it yet. /login is required.

If you choose the login method labeled "API" or "Console," you will be charged separately for usage. It is fine as long as the display on the screen says "Claude Pro."

Step 3: Requesting my first task

My first task was to create a table calculating the cost of the Adobe corporate version. When I asked in Japanese, Claude ran GridCraft (an Excel alternative) on its own and created the table in a few dozen seconds. Request text: Using gridcraft-cli, create a table calculating the monthly, annual, and 10-year total costs for 5 people using the Adobe corporate version (11,990 yen per person per month), and save it as "Adobe_Cost_Estimate.xlsx". Display the contents when finished. The resulting table: Period Cost (yen) Monthly 59,950 Annual 719,400 10-year total 7,194,000 The table contains formulas, so if you change the unit price or the number of people, the total will change automatically. When I followed up by asking, "Also add the case for 10 people," it corrected it right away.

You may be asked, "Do you want to execute this command?" along the way. Until you get used to it, it is safer to choose "1. Yes" to see how things go. In the current version, "Auto Mode" is the default, so it proceeds with safe operations without confirmation (you can toggle this with Shift + Tab).
