Revamped Claude Code: Fully Customize All Colors & Animated Backgrounds Starting Today

Just now, Anthropic's official developer account @ClaudeDevs posted a tweet: You can now apply custom skins for the Claude Code desktop app!

Say to Claude "I want a cyberpunk neon-style interface", and it will write the code by itself to modify its own interface —

All elements including colors, typography, and even dynamic animated backgrounds are fully applied.

Some users have modified Claude Code to look exactly like Bloomberg Terminal, with black background, green text, and dense data style that brings the full vibe of Wall Street traders the moment you open the screen.

Other users directly set the iconic green code rain from *The Matrix* as the dynamic background, with the character waterfall pouring down behind the dialog box, making you feel like Neo when writing code.

A user in the comment section summed it up precisely: Claude is turning into Discord.

This reminds me of WinAmp skins.

Exactly. More than 20 years ago, when we used WinAmp to listen to pirated MP3 files, the greatest fun was hunting for skins all over the internet: Star Wars themed, Final Fantasy themed, Diablo themed.

That was the era when "personalization" on the internet grew in the most unconstrained, wild way.

Today, that same vibe has been revived on AI programming tools.

210 Days of Waiting

The previous "theme system" of Claude Code desktop app was rather underwhelming, with only two modes: light mode and dark mode.

The terminal version was slightly better: in April, Anthropic added support for custom JSON theme files, opening a door for command line users.

But the desktop app only offered pure black or pure white, take it or leave it.

The developer community has long been fed up with this. The earliest posts requesting "custom themes" can be traced back to April 2026.

Some users complained that the pure black background was too harsh, some wanted the Dracula color scheme, and others hoped to make Claude Code visually consistent with their own VS Code.

All kinds of demands boil down to one sentence: Why can my code editor be full of various styles, while my AI programming tool can only have two colors, black and white?

From April to November, it took a full 210 days.

But interestingly, the final solution Anthropic offered is not an "appearance settings page". They did not make any theme selector, color palette, or a row of preset options for you to choose from at all.

They handed the paintbrush to Claude itself.

Specifically, Anthropic opened up deep customization capabilities for the desktop app's visual layer through the mods system launched in October this year.

The first way: Talk to Claude directly. Type a sentence in the dialog box like "Help me make a deep-sea blue theme with a particle animation background", Claude will write a piece of TypeScript code by itself, generate a mod plugin, call the $.theme.set interface to replace the background, and then use the ui.render hook to recolor all interface elements (user message bubbles, Claude reply area, loading animation, sidebar).

The second way: Start with the official theme-examples plugin. This is a set of ready-made theme templates provided by Anthropic, which you can install directly, or clone and modify to the style you want.

The operation process is extremely simple. You don't need to understand TypeScript, you don't need to write JSON configuration files manually, and you don't need to go through documents to study color value tokens.

You only need to open the Claude Code desktop app, describe the visual effect you want as if chatting with a person, and Claude will handle the rest on its own.

More Than Skins: The "Aesthetic Awakening" of AI Programming Tools

You might say: It's just changing colors and adding an animated background, it doesn't make the model any smarter, what's the point of making these fancy stuff?

There is nothing wrong with this statement if you said it two years ago.

But in the landscape of AI programming tools at the end of 2026, skin customization is far more important than you think.

First of all, a fact at the practical experience level: For heavy Claude Code users, spending 8 to 10 hours a day on this interface is a normal state.

A carefully adjusted low-contrast warm theme, or a soft dynamic background that gives the vision a sense of "breathing", brings tangible improvements to the experience of working for long hours.
