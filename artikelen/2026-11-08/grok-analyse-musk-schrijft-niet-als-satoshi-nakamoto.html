Grok AI 分析显示马斯克与中本聪写作风格无关

GitHub 开源项目用 Grok AI 结合文体学方法检验“马斯克即中本聪”猜想：中本聪 95.3% 的句号后接双空格、32.7% 使用英式拼写，马斯克这两项分别为 0 和 0.65%，函数词相似度仅列 66 位作者第 30，数据基本否定该理论。

GitHub 上一份新的开源分析对“埃隆·马斯克（Elon Musk）就是中本聪（Satoshi Nakamoto）”这一流传甚广的理论进行了检验，重点考察支持者最常引用的三项写作指纹。结果却显示，马斯克的写作风格与比特币匿名创造者几乎毫无共同之处。

文体学（Stylometry）是以统计手段研究写作风格、用以识别或比对作者身份的方法，衡量对象包括拼写偏好、标点习惯以及常见虚词的词频。“马斯克即中本聪”的说法已流传多年，部分源于 2017 年一位前 SpaceX 实习生的公开说法，但马斯克本人已多次否认自己创造了比特币。

2017 年 11 月 28 日，他曾在 X 上回应称：“不是真的。几年前有朋友给我转过一部分 BTC，但我不知道放哪了。”

句号后双空格：中本聪在 95.3% 的场合会在句号后使用两个空格，而马斯克在 X 上的原始帖子中一次都没有出现。
