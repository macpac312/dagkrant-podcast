Tesla to Launch Grok in the Middle East and Morocco With Upcoming Update 2026.32.6 - Not a Tesla App

Tesla is preparing to expand its Grok AI assistant to the Middle East. The company has updated several regional support pages, referencing the upcoming 2026.32.6 software update as a prerequisite for the feature.

Supported Countries

The updated pages include Israel, Qatar, the United Arab Emirates, Saudi Arabia, and Jordan. While Tesla’s official EMEA account announced earlier this week that Grok was rolling out in the Middle East and Morocco, it did not name individual countries or software version at that time.

Update 2026.32.6

The feature is tied to software update 2026.32.6, which has not yet been released to the public, but that’s expected to change in the next week or so. To run Grok, eligible vehicles must be equipped with an AMD Ryzen infotainment processor and have an active Premium Connectivity subscription or a Wi-Fi connection. Owners do not need to have a Grok account to use the in-car assistant.

What Grok Can Do

Once installed, drivers can launch Grok via the App Launcher, pressing the steering-wheel microphone button, or by using the “Hey Grok” voice activation. In Assistant mode, it handles core vehicle tasks including navigation, phone calls, media playback, climate adjustments, and answering questions using the digital owner’s manual. It can also set location-based reminders.

While the immediate focus of this rollout is regional expansion, Tesla continues to work on expanding Grok’s capabilities. Recent updates to the official owner’s manual reveal that the assistant will eventually be able to compose and send text messages via voice commands, though Tesla has not confirmed the release timing or which software build will introduce that functionality.

How to Access Grok

Owners in the supported regions will need to wait for software version 2026.32.6 (or later) to reach their vehicles, which can be checked by navigating to Controls > Software. Once the update is installed, the Grok app will show up in the App Launcher.

This marks another regional expansion for Grok, which is already active in North America, Europe, and parts of Asia. The next step is simply waiting to see how quickly the 2026.32.6 update begins hitting vehicles in these newly supported markets.
