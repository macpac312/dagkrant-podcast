Adobe is testing how well AI agents can use editing tools like a Photoshop professional would

Key Points

Adobe researchers built an AI agent for image editing that pairs a general-purpose editor with specialized tools. A standard language model compares results using measured data and picks the best one.

AI agents for image editing break complex requests into steps and typically retry failed steps with the same tools, while a separate model judges the output by eyeballing it.

Researchers at Adobe Research and UC San Diego want to change that with EditAgent, a system that works more like a pro in Photoshop, according to a new paper. It picks the right tool for each task and compares the result against the original using hard numbers.Ad

General-purpose editors fail at too many tasks

In a test of 600 image edits, blind-rated by five professionals, the general-purpose editor Flux-2-Klein-9B failed to produce a usable result 42.7 percent of the time. Specialized tools solved roughly two-thirds of those failures, especially for sharpening, rotation, and zooming. More retries with the same editor barely helped.Ad

The researchers also tested whether an agent does better by refining results step by step or by generating multiple variants in parallel. Iterative refinement piles up small errors because each round builds on an already altered image. Professionals preferred the parallel variants generated from the original in 78.5 percent of the comparisons where they picked a side. The agent needed only half as many evaluation passes. EditAgent is built on these two findings.

Hard numbers turn standard models into better judges

EditAgent plans a request in steps and, for each step, pits the general-purpose editor against matching specialized tools. A standard language model then compares all variants in a single pass.Ad

For each variant, the model gets a verification record with a close-up of the edited area, a change map of altered regions, and measured statistics on brightness and color. In one example, a photo was supposed to be gently brightened. The numbers showed the general-purpose editor overexposed it and shifted the colors warmer. The specialized tool stayed within spec.

The researchers tested this on their 600-edit benchmark. The judge model had to pick the best result from several candidates, and they counted how often it chose an image the professionals also rated as usable. For comparison, they ran models like EditScore that were fine-tuned on human ratings of image edits.Ad

Without the verification record, none of the seven language models tested could match the best fine-tuned model. With it, all seven beat every fine-tuned model. Qwen3.8-27B made a usable pick 81.3 percent of the time, compared to 74.8 percent for EditScore-72B. For the researchers, this suggests that what a judge model sees can matter more than how it was trained.Ad

After each round, EditAgent also checks whether later edits accidentally undid earlier ones. In the paper's example, the instruction "let in more daylight" makes a previously frosted window clear again. The agent catches the conflict and fixes it.

EditAgent improved the open-source editors Qwen-Image-Edit-2511 and Flux-2-Klein-9B across three benchmarks and outperformed seven other AI agents. On the EdiVal benchmark, the Qwen variant in its third editing round edged past the commercial models Seedream 4.0 and GPT-Image-1.5. But the agent needs about ten times as much compute as a single editor, and its performance depends on which tools are plugged in.

The agent generates training data for faster editors

The researchers also use EditAgent as a data source. Because the agent only keeps verified results, it produced about 26,000 training examples. Editors fine-tuned on that data performed better across all three benchmarks. Training data generated directly by FLUX, on the other hand, actually made FLUX worse. That tradeoff could make the agent's high compute costs worth it over time.

Adobe added AI agents to Photoshop, Premiere, and other Creative Cloud apps in June, starting as a public beta. Users describe what they want, and the agent handles the individual steps. How well these agents pick the right tools and check their own output is a question that applies directly to Adobe's shipping products. Black Forest Labs has since replaced the general-purpose model tested in the paper: the new Flux 3 Image Klein has 5.6 billion parameters, smaller than Flux 2 Klein, yet it scores higher than all other open models and even the commercial Flux 2 Pro in Black Forest Labs' internal tests.
