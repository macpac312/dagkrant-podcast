開發者好幾個月沒開VS Code 微軟CEO坦言：Claude Code改變了一切 | ETtoday AI科技 | ETtoday新聞雲

▲納德拉坦言Claude Code半年撼動VS Code地位。（圖／ANTHROPIC）

微軟執行長納德拉（Satya Nadella）近日談及 AI 程式開發工具 Claude Code 對軟體開發產業帶來的影響，指出 Anthropic 推出 Claude Code 後，短短約半年便改變開發者的工作習慣，連微軟長期打造的 VS Code 也面臨地位動搖。他認為，這代表軟體開發模式正從傳統程式碼編輯，逐漸轉向由 AI 執行程式開發任務。

根據科技媒體 Windows Latest 11 月 23 日報導，近期有不少開發者分享自己已經好幾個月沒有開啟 VS Code。納德拉表示，他完全理解這種現象，並坦言 Claude Code 的出現，讓傳統程式碼編輯器與整合式開發環境（IDE）在短短半年內失去過去的存在感。

納德拉指出，過去十多年來，微軟持續努力將 VS Code 打造成開發者的預設工作平台。不過，Claude Code 受到開發者青睞，也反映出軟體開發方式正在出現重大轉變，而微軟並未立即提出相應的解決方案。

儘管傳統 IDE 面臨挑戰，納德拉並不認為微軟已經失去機會。他指出，隨著微軟推出新一代決策模型，IDE 未來甚至可能迎來新一波發展。他提出的方向是，未來 IDE 的核心工作可能不再是由開發者親自編寫程式碼，而是撰寫完整的 Markdown（MD）說明文件，清楚描述軟體需求、功能規格與執行方式，再由 AI 負責後續開發工作。

微軟近期的產品更新也反映出這項調整方向。11 月 11 日推出的 VS Code 1.146 版本，加入 AI 代理收件匣與模型比較功能；11 月 18 日發布的 VS Code 1.147 則進一步加入模型路由功能，可依照不同任務，從使用者偏好的模型中選擇適合的工具。
