Welke desktop-app voor meerdere AI-agents tegelijk? De vergelijking

Acht desktop-apps laten tegenwoordig meerdere AI-codeeragents tegelijk aan hetzelfde project werken. Het gaat om Claude Code, Codex in de desktop-app van ChatGPT, Cursor, Antigravity, GitHub Copilot, JetBrains Air, Devin Desktop (het voormalige Windsurf) en Zed. De verschillen zitten in drie punten, namelijk waar de agents draaien, hoe de bestanden gescheiden blijven en wie de rekening van de modellen betaalt. Daar komen drie orchestrators van derden bij (Conductor, Superset en OpenCode desktop), die geen eigen modellen hebben en de agents van anderen laten draaien. De gegevens komen van de officiële pagina's van elke aanbieder en gelden per 15 oktober 2026.

Een AI-codeeragent is een programma dat de code van een project leest, aanpast en opdrachten uitvoert namens de ontwikkelaar, zonder bij elke stap op een instructie te wachten. Meerdere agents tegelijk laten werken bespaart tijd (de ene schrijft de tests terwijl de andere een bug verhelpt), maar levert een praktisch probleem op, want twee agents die in dezelfde bestanden schrijven overschrijven elkaar. Alle apps hieronder pakken dat probleem aan, elk op een eigen manier.

In Antigravity heeft Gemini 4 Argon voor AI Pro-gebruikers inmiddels een eigen weekquotum, los van de pot van Gemini 3.8 Flash.

Hoe twee agents die tegelijk werken gescheiden blijven

De acht apps gebruiken vier strategieën, vaak gecombineerd. De eerste is de worktree, oftewel een aparte werkkopie van dezelfde Git-repository met een eigen branch, waardoor twee agents aan hetzelfde project kunnen werken zonder elkaars bestanden aan te raken (dat kwam aan bod in de gids over worktrees voor AI-agents). De tweede is de externe machine, dat wil zeggen een virtuele machine in de cloud waarop de agent met een gekloonde kopie van de repository werkt. De derde is de Docker-container, die tools en afhankelijkheden op de eigen computer isoleert. De vierde, feitelijk het ontbreken van isolatie, houdt in dat iedereen dezelfde map deelt.

Die laatste weg heeft een prijs die de documentatie zonder omwegen benoemt. In de gids van JetBrains Air delen sessies binnen dezelfde taak één werkkopie en kunnen ze elkaars wijzigingen overschrijven, terwijl in Zed twee threads zonder eigen worktree in dezelfde bestanden werken. Daarom telt meer hoe een app agents isoleert dan hoeveel er te starten zijn.

Welke desktop-apps laten meerdere AI-agents tegelijk werken?

Het zijn er acht, namelijk Claude Code (Anthropic), Codex (OpenAI), Cursor, Antigravity (Google), GitHub Copilot, JetBrains Air, Devin Desktop en Zed. Alle acht starten meerdere sessies tegelijk en verschillen in isolatie (worktree, container of externe machine), in de plek waar ze draaien en in de beschikbare modellen.

Wat kosten ze, met welke modellen en tot hoeveel agents?

Geen van de acht documentaties noemt een maximaal aantal parallelle agents. De enige getallen die voorkomen zijn plafonds voor iets anders (25 worktrees per machine in Cursor, 20 per workspace in Devin Desktop, 10 nestingniveaus in Antigravity) en een instelling om de subagents van Codex te begrenzen, zonder opgegeven standaardwaarde.

De acht apps één voor één

Claude Code desktop

Claude Code is de programmeerassistent van Anthropic en leeft in de desktop-app van Claude op het tabblad Code. Elk gesprek is een sessie en vanuit de zijbalk worden er andere geopend met Cmd+N (Ctrl+N op Windows). Wie Cmd of Ctrl ingedrukt houdt terwijl hij op een sessie klikt, opent die in een tweede paneel naast de eerste. De isolatie is een vakje om aan te vinken, namelijk de worktree naast de naam van de branch. De documentatie benadrukt dat daarvoor een Git-repository nodig is.

De sessies kunnen draaien op de eigen computer, in de cloud van Anthropic (ze lopen door ook nadat de app is gesloten), via SSH of in een WSL-distributie op Windows. De rekening is die van het abonnement, want het quotum wordt gedeeld door alle onderdelen van Claude Code en de lijst met modellen bevat alleen Claude-modellen. Op 14 oktober zijn er ook geneste sessies en opgeslagen omgevingen bijgekomen, beschreven in het artikel over de nieuwigheden van de desktop-app van Claude Code, terwijl het herontwerp van april de zijbalk had ingevoerd. We legden ook uit hoe sessies onderling berichten kunnen uitwisselen.

Codex in de desktop-app van ChatGPT

Sinds 9 juli 2026 maakt Codex, de programmeeragent van OpenAI, deel uit van de desktop-app van ChatGPT op macOS en Windows, terwijl Linux een preview heeft. Een project bundelt meerdere parallelle chats en voor elke chat kiest men uit drie modi. In de lokale modus werkt de agent in de huidige map. De worktree-modus isoleert de wijzigingen in een Git-kopie op de eigen computer. In de cloudmodus start een externe taak in een eigen workspace, opgebouwd uit een herbruikbare omgeving.

Wie de cloud gebruikt, moet weten dat lokale bestanden, draaiende processen, ingelogde browsersessies en VPN's niet automatisch naar de externe taak worden overgebracht. Er zijn ook projecten op een SSH-host en subagents, waarvoor een instelling het aantal geopende threads begrenst zonder de standaardwaarde te vermelden. Wat de kosten betreft neemt de pagina met abonnementen Codex op in alle ChatGPT-abonnementen en waarschuwt die dat cloudtaken meer quotum kunnen verbruiken dan lokale berichten. Over de cloudkant schreven we toen Codex Cloud op web en telefoon verscheen.

Cursor en zijn Agents Window

Cursor is de code-editor met agents van Anysphere en sinds 2 april 2026 (versie 3) is de Agents Window het venster waarin meerdere agents op meerdere repositories en in meerdere omgevingen kunnen werken, lokaal, in worktrees, in de cloud en via SSH. Het is geen aparte app, want het venster opent vanuit de editor en kan naast de code blijven staan. Het commando /multitask voert verzoeken uit als asynchrone subagents in plaats van ze in de wachtrij te zetten, terwijl /best-of-n dezelfde taak op meerdere modellen laat draaien, elk in een eigen worktree.

De cloudagents draaien in geïsoleerde virtuele machines en er kunnen er, zo zegt de speciale pagina, zoveel worden gestart als men wil. Daarvoor is wel een betaald abonnement nodig en het gebruik wordt betaald tegen de API-prijs van het gekozen model, met een uitgavenlimiet die bij de eerste start wordt ingesteld. Het enige numerieke plafond betreft de worktrees, standaard 25 per machine. Over de mobiele kant gaat het artikel over Cursor op de iPhone.

Antigravity 2.0 van Google

Op 19 mei 2026 presenteerde Google Antigravity 2.0 als zelfstandige desktop-applicatie, beschikbaar voor macOS, Linux en Windows (de documentatie noemt ook Googlebook), naast de opdrachtregel, de IDE en de SDK. Het parallelle werken loopt via subagents, want een bovenliggende agent kan er meerdere tegelijk aanroepen, elk als eigen sessie die op de achtergrond werkt. De workspace van een subagent wordt gekozen uit overgenomen, gedeeld of geïsoleerd in een worktree op een branch. Goedkeuringsverzoeken komen terecht in de hoofdinterface.

Voorlopig is de uitvoering lokaal. Google zegt vooruit te kijken naar agents in de cloud, maar de startgids beschrijft alleen de modi op de eigen machine. De gebruikslimieten volgen, legt de pagina met abonnementen uit, het werk van de agent meer dan het aantal prompts. Over Antigravity 2.0 op Google I/O en over het commando /boost schreven we al eerder.

GitHub Copilot app

De GitHub Copilot app is een desktop-applicatie voor softwareontwikkeling met agents, sinds 17 juni 2026 algemeen beschikbaar voor macOS, Windows en Linux. Ze laat meerdere geïsoleerde sessies tegelijk draaien, elk met een eigen worktree en branch. Per sessie kiest men het model, de redeneerinspanning en een van de drie modi (Interactive, Plan, Autopilot).

De sessie kan starten in een nieuwe worktree, in de lokale repository of in een cloudsandbox gehost door GitHub, die alles ver van de eigen computer houdt. De app zit in alle Copilot-abonnementen en voor Business en Enterprise moet de beheerder het bijbehorende beleid ingeschakeld laten. Het gebruik wordt in AI-credits geteld en de gids raadt aan het model af te stemmen op de moeilijkheid van de taak.

JetBrains Air

JetBrains, het bedrijf achter ontwikkelomgevingen als IntelliJ, lanceerde Air in maart 2026 in Public Preview als omgeving om taken aan meerdere agents te delegeren. Bij de lancering was de app gratis op macOS, met Windows en Linux aangekondigd. Volgens de gids over multitasking kunnen meerdere taken tegelijk draaien en kunnen aan een taak meerdere sessies worden toegevoegd, met drie uitvoeringsomgevingen, namelijk lokaal, Git-worktree of Docker-container.

De meegeleverde agents zijn Codex, Claude Agent, Gemini CLI en Junie. De kosten hangen af van welke men gebruikt, want er is een JetBrains AI-abonnement nodig of de abonnementen of sleutels van de aanbieders van de agents. De gids geeft een expliciete waarschuwing over sessies binnen dezelfde taak, die de werkkopie delen en elkaar kunnen overschrijven.

Devin Desktop, het voormalige Windsurf

Windsurf, de editor met agents van Cognition, is op 2 juni 2026 Devin Desktop geworden en het bedrijf laat weten dat de prijzen ongewijzigd blijven. Het hart van het parallelle werken is het Agent Command Center, een bord waarop de agents per status zijn gegroepeerd. Lokale agents draaien in de editor, cloudagents zijn sessies van Devin op aparte virtuele machines. Beide soorten staan op hetzelfde bord. Er zijn systeemmeldingen voor afgeronde of wachtende sessies, maar die staan standaard uit.

De worktree-modus wordt aan het begin van de sessie gekozen en de documentatie stelt een maximum van 20 worktrees per workspace vast, waarbij de oudste worden verwijderd zodra er een nieuwe wordt gemaakt. Agents van derden zoals Codex CLI en Claude Agent kunnen in het commandocentrum draaien via het ACP-protocol, maar alleen met de abonnementen Pro, Max en Teams. De aanbieder van de agent factureert ze rechtstreeks.

Zed is een code-editor en kreeg met de aankondiging van 22 april 2026 een functie genaamd Parallel Agents, die vanuit de zijbalk met threads meerdere agent- en terminalthreads tegelijk laat draaien. Elke thread heeft een eigen agent, een eigen contextvenster en een eigen geschiedenis. Er zijn drie typen, namelijk de agent van Zed, een externe agent en een terminal. De isolatie wordt per thread gekozen, want er kan een nieuwe thread in een eigen worktree worden gestart wanneer twee threads dezelfde bestanden dreigen te raken.

De vermelde externe agents zijn Claude, Codex, OpenCode, Copilot, Cursor en Pi, naast elke agent die compatibel is met ACP. Het gratis abonnement staat externe agents en eigen API-sleutels toe, terwijl het gebruik van gehoste modellen per token wordt gemeten tegen de lijstprijs plus 10%.

En de orchestrators van derden?

Naast de apps van de aanbieders bestaat een tweede familie, die van de orchestrators, oftewel apps die geen modellen maken en de agents van anderen (Claude Code, Codex, Cursor) starten en ze in worktrees gescheiden houden. Drie ervan hebben officiële documentatie op de eigen site en staan daarom hier naast de acht.

Conductor

Conductor is een app voor macOS en de installatiepagina schrijft dat de app voor Windows en Linux nog niet beschikbaar is. Elke workspace krijgt een eigen branch en een eigen werkkopie. In dezelfde workspace kunnen meerdere agents draaien wanneer het werk bij dezelfde branch hoort, met de kanttekening dat ze dezelfde bestanden kunnen aanpassen. De pagina over worktrees stelt dat de isolatie het werk dient en niet de veiligheid, omdat agents en opdrachten op de Mac draaien met de rechten van de gebruiker, tenzij er strengere controles zijn. In het gratis abonnement blijven de lokale workspaces met parallelle agents beschikbaar, terwijl de cloudworkspaces bij de betaalde abonnementen horen.

Superset

Superset (heeft niets te maken met Apache Superset, de tool voor datagrafieken) presenteert zich als een source-available platform om programmeeragents parallel uit te voeren, onder de licentie Elastic License 2.0. Het bestaat als desktop-app, app voor iPhone en iPad, opdrachtregel en MCP-server. Elke taak heeft een workspace die een Git-worktree op een eigen branch is. Conflicten tussen agents worden opgelost op het moment dat de wijzigingen worden samengevoegd. Het draait op macOS, met Linux in experimentele versie, terwijl het voor Windows nog niet beschikbaar is. Het project kondigde op 12 oktober aan dat het vóór het einde van de maand van naam verandert, waarbij product en prijzen ongewijzigd blijven. De hier gebruikte naam is dus mogelijk niet de definitieve.

OpenCode desktop

OpenCode is een open-source agent voor terminal, IDE of desktop en de functie Multi-session start meerdere agents parallel in hetzelfde project. De desktop-app is te downloaden voor macOS, Windows en Linux. De README van de repository bestempelt haar als beta, terwijl de downloadpagina dat label niet gebruikt. Op het vlak van isolatie voert de changelog van 12 oktober tools in om worktrees te maken, weer te geven en te verwijderen. De site noemt meer dan 75 modelaanbieders, lokale inbegrepen. De prijs van de app staat nergens op de officiële pagina's.

Kiezen naar je manier van werken

Wie van aanbieder wil wisselen zonder van app te wisselen, kan terecht bij JetBrains Air, Zed en Devin Desktop, die zijn gebouwd om agents van verschillende aanbieders te huisvesten. Cursor laat kiezen uit modellen van meerdere bedrijven. Conductor en Superset doen hetzelfde als orchestrators, met Claude Code, Codex en Cursor Agent. Claude Code, Codex en Antigravity blijven vooral gebonden aan de modellen van de eigen aanbieder.
