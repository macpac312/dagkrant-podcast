Claude Mods: Flipping the Harness Inside Out

For the last few weeks I’ve used Claude Mods to mold Claude Code to my AI engineering workflow. Claude Code is great out of the box, but every engineering workflow is different.Claude Modslet you make Claude Code yours, in the way you want to pay attention.

The “paying attention” part is now the most important thing.

In a recent Latent Space post,The Evolution of the Agent Harness, I argued that as models absorb more of the harness into their weights,the part that’s left faces the human.It becomes theAttention Interface: the layer that decides when the agent interrupts you, what it shows you, and which decisions it needs you to make. Claude Mods are an early version of the Attention Interface, and one you can shape yourself.

Here’s my bet: ultimately,the harness becomes a platform that other companies build on, with models as the engine. Just as the browser became a platform for web apps, the harness could become a platform for the interfaces between people and agents.

Claude Mods: What is it?

A mod isa Claude Code pluginthat consists ofTypeScript or JavaScript functionsthat run inside Claude Code. These functions customize the behavior and appearance of the interface in the CLI and Desktop.Mods respond to events, like a prompt, tool call or interface render. They can observe the event, modify how it’s rendered, and handle it in place of the default behavior.

Claude Mods aremiddleware for the agent harness. They inject code that changes Claude Code’s execution and rendering flow, changing how the application behaves at runtime.

Claude Mods let the human and the agent build the human-facing part of the harness together. You can now work with Claude to design how Claude works with you. That is the essence of the “Attention Interface.”

The harness reversal

The agent harness started as an interface between the agent and the machine it runs on. It lets you prompt the agent and the agent then sends commands, edits files and calls tools. Now it’s gradually becoming a way for the agent to interface with the human.

Claude Mods let you reverse the direction of the harness.Rather than the harness pointing from the agent to the machine, you point it from the agent to the human operator, and the harness becomes a way to interface with human attention.

Claude Mods make the human layer programmable, by the human who uses Claude.

Claude can also build mods for you.Claude Code has abuilt-in skillthat teaches it how to build mods, so you can ask for the mod you want in plain language and Claude will build it.

Mods in practice

Some of Claude Code’s own features are already mods. Anthropic has shippedsix of them built-in. You can see these by running /plugin and openingInstalled, where they’re listed under Built-in:

agents-md:loads AGENTS.md as project instructions.

diff:takes over /diff and draws its pane.

plugin-authoring:gives Claude the skill it uses to write mods for you.

sec-default:guards what your organization manages from the mods a user installs.

telemetry:sends the analytics records that Claude Code and its built-in mods log.

you-should-know:a side agent that shows a note above the prompt when it finds something you might have missed. It’s the only one that’s off by default.

Most of these work in the background, which is interesting because it means Anthropic is building parts of Claude Code as mods — even parts you may not notice. The one I’ve turned on myself isYou Should Know.

Here are the two mods I’ve found most useful in practice: one a built-in, and one I built myself.

1. You Should Know

This is a native Claude Code plugin built by Anthropic.It runs a side-agent that observes the main agent while it worksand flags important information you’re likely to miss. Think about it like: tool calls and decisions that have a material impact on the output, but aren’t necessarily easily visible because they’re buried in the agent trace. It comes built into Claude Code, but it’s off until youturn it on.

Here’s a real example. I asked Claude Code to simplify the noisy UI text in one of my personal projects. The main agent trimmed the copy on the Compare screen, installed the new build and took before-and-after screenshots. Everything looked done.

ThenYou Should Knowflagged something for me. CompareView.swift, the file the agent was editing, already had uncommitted work in it — and so did about 45 other files. If I later discarded the demo edits, I’d throw away that earlier unfinished work too. Its suggestion was to commit or stash the earlier work first.

In this case, theYou Should Knowmod saved me from discarding work unintentionally.

2. Next Steps Supervisor

This mod only runsafter a turn that edited files, ran commands or made 8 or more tool calls.In the screenshot below, you’ll see six different pieces of information flagged for your attention.Next Steps Supervisorthen suggests a next step to take, as a clickable button which sends the instruction as a message to Claude Code. This mod is available as part ofModSmith— an open-source Claude Code plugin I built with several different built-in mods, as well as a template Claude can use to build new mods that work together.

Attention Interfaces elsewhere

Anthropic isn’t the only company that’s building an Attention Interface. Two recent products, one from OpenAI and one from Cursor, point in the same direction. Using the newChatGPT Intelligent UIandCursor’s PR Routing & Approvalas a frame of reference shows what’s unique about Claude Mods.

ChatGPT’s Intelligent UI

On October 7, OpenAI shipped GPT-6 inside ChatGPT alongside a new ChatGPT interface it callsIntelligent UI. Rather than answering only in text,ChatGPT now can generate an interface as it answers: charts, maps, checklists, forms, and small tools like a bill splitter or a savings calculator. All generated on the fly by the model as a type ofgenerative UI.

In one of OpenAI’s examples, ChatGPT replies with multiple-choice follow-up questions to narrow down what you’re looking for. Think about it like: the model decides when it needs your judgment, then builds the interface for you to give it.
