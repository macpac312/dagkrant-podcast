Linus Torvalds Says He Likes Using AI, While His New Kernel Branch Credits Claude Code

Linus Torvalds has a new branch in his own kernel repository named noref-filemap-read-with-llm.

It holds an eight-patch series built on Linux 7.3-rc6 plus fixes, and its commit message gives no kernel release target for merging it.

While the commit message is long and technical, the change itself is easy to describe.

What he changed

When many threads read the same file, the kernel serves them from the page cache, its in-memory copy of recently read data. Today, each read takes a hold of the cached data and releases it afterwards.

Every thread updates the same counter to do so, resulting in the threads tripping over each other. The issue dates to 2024, when Matthew Wilcox flagged it, citing a customer's workload.

Linus' series of patches skips that step. To make that safe, memory that leaves the cache is not handed out for reuse until a short period has passed, so a reader can copy data straight out without holding anything.

The cost is that more memory sits idle for a moment.

The payoff, measured on his own laptop with some security protections switched off, is that eight threads reading one file went from about 10 million reads per second to between 30 and 33 million.

Linus ran the measurements himself, but for the rest, the commit message credits Claude Code, working under his direction. That includes a draft of the message itself, the code and test programs, and the review behind its list of known problems.

This is not the first time he has used AI on kernel work. In August, he used it to help fix a bug in the Intel Xe graphics driver.

What he said in Prague

Linus spoke with his long-time friend, Dirk Hohndel, the head of Ericsson Software Technology, at Open Source Summit Europe in Prague on Friday.

ZDNet's Steven Vaughan-Nichols, who was in attendance, quotes Linus, saying, "I actually really like using AI."

He said he used to think AI was not very good but has changed his mind. In his view, it works well as long as it is treated as a tool, and it makes programming more enjoyable for him.

His own example was a guitar pedal project with an interface he had written in C. He wanted a more modern look and tried AI for it, saying, "I use AI to do the things that I'm bad at."

He also defended vibe coding as "a wonderful way to find joy in programming," mainly for newcomers, and says that while AI is improving the code base, the load it puts on maintainers has become a real problem.

This again shows how much Linus’ stance has changed when it comes to AI. In 2024, he called the AI industry "90 percent marketing and 10 percent reality." Now, he is actively using it for kernel work.
