Claude Code desktop opent parallelle taken nu als geneste sessies in plaats van losse vensters.

Opgeslagen omgevingen maken een werkplek reproduceerbaar en delen een agent-opzet tussen taken.

macOS en Windows zijn volledig ondersteund, Linux blijft in bèta: de volgorde van prioriteiten is zichtbaar.

De strijd met OpenAI's Codex verschuift van modelkwaliteit naar de orkestratie eromheen.

Van chatvenster naar werkbank

Met de update van 14 oktober laat Anthropic zien waar Claude Code naartoe beweegt. Wie in de desktopapp een parallelle taak start, krijgt die niet langer als losstaand gesprek, maar als geneste sessie onder de bovenliggende opdracht. Daarnaast zijn omgevingen op te slaan: de combinatie van map, instellingen en rechten die een ontwikkelaar voor een project inricht, hoeft niet telkens opnieuw te worden opgebouwd. Dat klinkt als een gebruiksgemak, maar het is een architectuurkeuze. Een agent die werk uitbesteedt aan sub-sessies heeft een hiërarchie nodig, en een hiërarchie vraagt om een plek waar je haar kunt overzien. De terminal was daarvoor nooit gebouwd. Bij deze analyse waren geen brontekst of release notes beschikbaar. De details van de update komen dus uit Anthropics aankondiging in samenvatting, aangevuld met eerdere ontwikkelingen.

Waarom Linux achterblijft

Opvallender dan de nieuwe functies is wat ontbreekt. Linux blijft in bèta, terwijl macOS en Windows volledig worden ondersteund. Dat past bij een patroon in de sector: de desktopmarkt voor ontwikkelaars is groot, maar de Linux-populatie is verdeeld over distributies, venstersystemen en pakketformaten, wat de testlast verhoogt. Er is ook een ironie. Claude Code is in de kern een terminalprogramma, en daar is Linux van oudsher thuis. Wie op Linux werkt, heeft de CLI nog altijd tot zijn beschikking. Voor die groep is de bèta dus een gemis aan gemak, geen blokkade. Dat verklaart waarom Anthropic zich de prioritering kan veroorloven.

Tegelijk is de timing veelzeggend. Eerder dit jaar kregen Claude Code-sessies de mogelijkheid elkaar berichten te sturen, lokaal of via Anthropics servers. Geneste sessies zijn de zichtbare, bestuurbare vorm van diezelfde gedachte. Een analist wees destijds al op het governance-aspect: agent-tot-agentverkeer vraagt om een eigen categorie van toezicht. Ook de auto mode hoort in dit rijtje. Die keurt acties goed zonder tussenkomst van een mens en blokkeerde in tests 89 procent van de gevaarlijke commando's. Dat betekent ook dat 11 procent niet werd tegengehouden, een cijfer dat zwaarder weegt zodra meerdere sessies tegelijk draaien.

Wie meer agents tegelijk laat werken, verlegt het knelpunt van schrijven naar beoordelen.

Concurrentie en toezicht

OpenAI rolde Codex onlangs uit in de ChatGPT-app op iOS en Android, als antwoord op Anthropics Dispatch, en meldt vier miljoen wekelijkse gebruikers. Beide partijen concurreren nu minder op de vraag wie de beste code schrijft en meer op wie de beste werkomgeving biedt: sessies, geheugen, rechten en overzicht. Voor Nederlandse en Europese organisaties, ook gereguleerde zoals banken, ligt de vraag elders. Een boom van parallelle sessies vermenigvuldigt de punten waarop een agent bestanden leest of commando's uitvoert. Opgeslagen omgevingen kunnen daarbij helpen, want een vastgelegde configuratie is controleerbaar en herhaalbaar. Ze kunnen ook een slechte instelling snel verspreiden. De waarde hangt dus af van wie de omgeving beheert.

Conclusie

Deze update maakt van Claude Code geen slimmere programmeur, wel een beter bestuurbare. Dat is de juiste investering, want de beperking zit niet meer in het genereren van code maar in het overzien ervan. Linux in bèta laat zien dat Anthropic kiest voor de grootste gebruikersgroepen, niet voor de meest trouwe. De echte toets komt wanneer organisaties opgeslagen omgevingen als beleidsinstrument gaan gebruiken. Dan wordt een handige functie een governance-vraag.
