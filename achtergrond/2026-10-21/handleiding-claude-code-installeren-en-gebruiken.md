Technobezz publiceerde een stap-voor-stap-handleiding voor Claude Code van Anthropic.

De tool draait in de terminal en werkt direct in de bestanden van een project.

Gebruik groeit van Linus Torvalds tot aanvallers in de CyberXero-campagne.

Het gemak van installeren maakt verstandig omgaan met rechten belangrijker.

Van chatvenster naar terminal

Dat een techsite als Technobezz een basishandleiding voor Claude Code publiceert, zegt iets over het publiek dat de tool inmiddels bereikt. Claude Code, begin 2025 door Anthropic gelanceerd als experiment, is een assistent die niet in een chatvenster maar in de terminal draait, het zwarte opdrachtscherm van programmeurs. Dat verschil is fundamenteel. Een chatbot geeft codefragmenten die je zelf moet plakken; Claude Code werkt direct in de bestanden van een project, voert commando's uit en kan tests draaien. De opzet is daarbij eenvoudig gehouden: installeren met één opdracht, inloggen met een Claude-account of API-sleutel, en het programma starten in de map van een project. Wie de stappen volgt, heeft binnen enkele minuten een assistent die de hele codebase kan doorzoeken. Precies die lage drempel trekt nu ook mensen aan die geen ervaren ontwikkelaar zijn.

Van Torvalds tot aanvallers

Hoe breed de tool is doorgedrongen, blijkt uit twee andere berichten in deze krant. Linux-schepper Linus Torvalds, jarenlang sceptisch over hypes, erkent dat AI hem helpt, en een patch in een nieuwe kernelbranch vermeldt Claude Code als hulpmiddel. Dat is een symbolische mijlpaal: de kernel is een van de meest kritisch beoordeelde codebases ter wereld. Tegelijk meldt beveiligingsbedrijf SOCRadar dat aanvallers Claude Code inzetten bij de CyberXero-campagne. Dezelfde eigenschappen die de tool nuttig maken, zelfstandig code schrijven en uitvoeren, maken haar ook bruikbaar voor kwaadwillenden. Anthropic heeft eerder zelf gerapporteerd over misbruik van zijn modellen bij cyberaanvallen en zegt zulke accounts te blokkeren. Voor beginnende gebruikers ligt de les dichterbij huis: een assistent die commando's kan uitvoeren, verdient dezelfde voorzichtigheid als elk ander programma met toegang tot je computer.

Gevolgen voor ontwikkelaars en organisaties

Voor individuele programmeurs verandert vooral het werkritme. Routinetaken als het schrijven van tests, het opschonen van code of het uitzoeken van een onbekende codebase gaan sneller, waardoor de nadruk verschuift naar het beoordelen van wat de assistent voorstelt. Voor organisaties liggen de vragen elders. Wie Claude Code toelaat op bedrijfslaptops, moet bepalen welke projecten de tool mag zien, welke commando's zonder toestemming mogen draaien en hoe gevoelige gegevens buiten beeld blijven. Het CLAUDE.md-bestand en de rechteninstellingen zijn daarvoor bedoeld, maar alleen effectief als ze bewust worden ingericht. Het voorbeeld van de CyberXero-campagne laat zien dat beveiligingsteams AI-codeertools inmiddels ook als potentieel aanvalsmiddel moeten beschouwen. Tegelijk wijst de vermelding in de Linux-kernel de andere kant op: ook de strengste open-sourcegemeenschappen accepteren AI-hulp, zolang een mens verantwoordelijk blijft voor elke regel die wordt ingediend.

Conclusie

Een handleiding als die van Technobezz markeert de overgang van nichegereedschap naar massaproduct. Claude Code is eenvoudig te installeren, en dat is zowel de kracht als het risico. Wie het gebruikt, doet er goed aan klein te beginnen: in een testproject, met toestemming per wijziging en met versiebeheer als vangnet. De belangrijkste stap staat in geen enkele installatiehandleiding: begrijpen wat je de assistent laat doen, voordat je op ja drukt.
