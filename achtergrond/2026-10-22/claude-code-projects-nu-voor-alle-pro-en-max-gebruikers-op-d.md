Claude Code Projects is open voor alle Pro- en Max-gebruikers op de wachtlijst.

Projects bundelt context en bestanden per project in plaats van per losse sessie.

Anthropic verbreedt zo de toegang tot een functie die eerst beperkt beschikbaar was.

Details over functies en voorwaarden zijn in de berichtgeving nog schaars.

Wat er bekend is

Anthropic heeft Claude Code Projects beschikbaar gemaakt voor alle gebruikers van de Pro- en Max-abonnementen die op de wachtlijst stonden, meldt Pasquale Pillitteri. Projects bundelt context en bestanden per project. Meer details staan niet in het beschikbare materiaal: hoe lang de wachtlijst was, welke extra functies erbij horen en of er gebruikslimieten gelden, is niet bekend. Het principe is wel duidelijk. Wie met een AI-assistent aan software werkt, moet die assistent telkens uitleggen hoe een codebase in elkaar zit, welke afspraken gelden en welke bestanden ertoe doen. Door dat per project vast te leggen, hoeft dat niet bij elke nieuwe sessie opnieuw. Dat is geen spectaculaire doorbraak, maar wel het soort functie dat het verschil maakt tussen een handige chatbot en een werkpaard voor dagelijks gebruik.

Waarom context de kern is

De waarde van een codeerassistent hangt sterk af van wat hij weet over het project. Een model dat de structuur, de conventies en de recente wijzigingen kent, maakt minder fouten en hoeft minder te raden. Dat is ook waarom het bericht dat Linus Torvalds, de schepper van Linux, met Claude Code aan een verbetering van de Linux-kernel werkt, zoveel aandacht trekt: de kernel is een van de grootste en meest kritische codebases ter wereld. Of Torvalds daarbij Projects gebruikt, is niet bekend. Wel laat het zien dat AI-codeertools inmiddels worden ingezet voor serieus werk door ervaren ontwikkelaars, en dat de vraag hoe zo'n tool context vasthoudt en organiseert steeds belangrijker wordt.

Conclusie

Het openen van de wachtlijst is een kleine stap met een duidelijke richting: Anthropic zet in op Claude Code als dagelijks gereedschap voor ontwikkelaars, en context per project is daarvoor een basisvoorwaarde. De concurrentie op AI-codeertools is groot, en wie de assistent het best laat onthouden waar hij mee bezig is, heeft een voorsprong. Hoeveel Projects in de praktijk toevoegt, moet blijken nu een bredere groep gebruikers ermee aan de slag gaat.
