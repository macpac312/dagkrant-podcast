Wat er ligt

Meta geeft toe dat de gelijkenis van Muse met OpenClaw geen toeval is, schrijft TechCrunch. CNBC ziet het aandeel uitbreken na de lancering. The Verge: Meta moest een exploit dichten waarmee aanvallers de agent konden besturen.

De mechaniek

Een agent die op een andermans ontwerp lijkt en op dag twee een zero-day heeft, is geen toekomstmuziek. Het is de huidige release-cyclus: ship, patch, ontken de inspiratie tot je hem toegeeft. 404 Media zag bovendien testers die menselijke callcenters achter ‘Muse-gesprekken’ vermoeden.

Wat het verschuift

OpenAI zou features ontwikkelen om Grok Bot en Muse te pareren. Drie labs, één productcategorie, nul rust. De agent is de nieuwe homepage. De homepage is nog niet veilig.

Conclusie

Geen toeval is een auteursrechtelijke zin in een productblog.

Een agent met een zero-day op dag twee is geen kinderfout. Het is de drempel van de categorie.

Wie callcenter achter de agent vermoedt, vermoedt de waarheid die de demo verbergt: volume eerst, autonomie later.
