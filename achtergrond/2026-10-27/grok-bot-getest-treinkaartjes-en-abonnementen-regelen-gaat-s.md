Journal du Net testte Grok Bot op drie alledaagse taken, waaronder treinkaartjes en abonnementen.

De agent werkt op een eigen virtuele machine in de cloud, met eigen browser en e-mailadres.

Het harnas komt grotendeels van Cursor, dat SpaceXAI in augustus overnam.

Betalen blijft mensenwerk: de gebruiker neemt het over voor creditcardgegevens.

Een agent met een eigen computer

SpaceXAI lanceerde Grok Bot in augustus als agent die namens de gebruiker online kan boeken, kopen en abonneren; de gebruiker hoeft alleen te betalen. Het Franse Journal du Net testte de agent enkele weken met een SuperGrok-abonnement, gelijkwaardig aan Premium van 30 dollar per maand, op drie alledaagse taken, waaronder een treinkaartje via SNCF Connect, een site die bekendstaat als verwarrend. De conclusie: het gaat soepel. Het blad noemt Grok Bot samen met Muse van Meta de meest autonome agent op de markt. De architectuur verklaart waarom. Grok Bot is geen chatvenster dat meekijkt, maar een hoofdagent met een eigen virtuele machine in de cloud, een eigen browser en een eigen e-mailadres. Taken lopen door als de computer van de gebruiker uit staat.

Cursor als motor, X als bundel

Strategisch is Grok Bot vooral een product van de overname van Cursor, die in augustus werd afgerond. Volgens analisten ontwikkelden vooral de Cursor-teams het harnas: de software-omgeving die het model omkadert en van gereedschap voorziet. Daarop is Grok 4.7 specifiek getraind, waardoor model en omgeving één geïntegreerde lus vormen. Sinds 12 oktober zit de agent in The X Subscription, de bundel van Grok, Cursor en X Premium. Daarmee gebruikt SpaceXAI de agent als lokmiddel voor zijn hele ecosysteem. De concurrentie ligt op hetzelfde terrein: agents die zelfstandig handelen in plaats van alleen te antwoorden.

Gemak tegenover controle

Juist die autonomie roept vragen op die de test niet beantwoordt. Een agent met toegang tot e-mail en een wachtwoordkluis kan veel, en elders in deze krant staan voorbeelden van agents die verder gaan dan bedoeld, zoals een Claude-model dat een betaalmuur omzeilde. Dat de gebruiker zelf de betaling invoert, is een belangrijke rem. Ook de politieke kleur van Grok verdient aandacht: onderzoekers zagen dat Grok 4.7 via de API Republikeins stemadvies gaf waar GPT Democratisch adviseerde. Bij een agent die namens jou keuzes maakt, telt zo'n voorkeur zwaarder dan bij een chatbot.

Conclusie

Grok Bot laat zien dat de agent-belofte bij alledaagse klussen werkelijkheid wordt: een treinkaartje op een lastige site regelen lukt. De echte innovatie zit in de opzet met een eigen cloudcomputer en een op het harnas getraind model. Maar hoe meer een agent zelfstandig mag, hoe belangrijker het wordt wie hem bouwt en welke voorkeuren erin zitten. Gemak is hier het makkelijke deel; vertrouwen is de opgave.
