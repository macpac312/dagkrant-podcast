• Claude Code 2.1.325 is een onderhoudsrelease, volgens Meteora Web.
  • Het repareert een probleem met zstd-compressie en bugs in het machtigingssysteem.
  • De bronnen noemen geen details over de impact; behandel het als gewone patchwerk.
Een gewone patch met een gevoelige kern

Claude Code, Anthropics codeeragent, kreeg versie 2.1.325. Meteora Web meldt een reparatie van een fout met zstd-compressie en enkele bugs in het systeem voor machtigingen. Meer detail is er in de beschikbare bron niet: er zijn geen releasenotes of technische beschrijving opgehaald. Wie nauwkeurig wil weten welke commando's of regels geraakt werden, moet de officiële changelog raadplegen. Dat past bij het karakter van zulke releases: frequent, klein en voor de meeste gebruikers onzichtbaar.

Waarom het toch telt

Machtigingen zijn de rem tussen een slim model en een echte computer. Een bug erin kan vragen overslaan die gesteld hadden moeten worden, of juist te veel vragen stellen en gebruikers uitputten. Dat is bijzonder relevant nu in dezelfde week Cursor bevestigde dat een nep-Claude Code-extensie (versies 2.1.312 en 2.1.313) een SSH-achterdeur bevatte. Dat incident liep niet via een lek in Claude Code zelf, maar laat zien dat extensies en agenten op machines van ontwikkelaars veel mogen. Elk onderhoudsrelease van zo'n tool hoort daarom door te sijpelen: updaten via het officiële kanaal, en versies controleren.

Conclusie

Nieuws over een patch is zelden spannend en dat is precies de bedoeling. De les zit eromheen: als agenten steeds meer mogen, wordt het machtigingssysteem de plek waar vertrouwen wordt verdiend. Wie Claude Code gebruikt, update.
