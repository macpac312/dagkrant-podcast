Het nieuws

Anthropic herlanceert Projects in Claude Code, schrijft The Verge. Gebruikers draaien meerdere agents onder één dak, met gedeeld geheugen, doelen en een bibliotheek bestanden. Threads doen taken parallel; een coordinator stuurt. The Decoder: Anthropic blijft duwen richting autonome coding.

Dat is de productvorm van het OpenAI-briefjesprobleem. Wie parallel laat werken, moet de coordinator loggen. Grok Bot en andere orchestrators kennen het patroon. Claude Code maakt het een default.

Voor developers is het snelheid. Voor security is het een aanvalsoppervlak met geheugen.

Analyse

Shared memory is een feature en een leak.

Een coordinator zonder audit trail is OpenAI’s briefje met een UI.

Autonomous coding verkoopt. Incident response erft de threads.
