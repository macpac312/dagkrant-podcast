Van gereedschapskist naar aandachtslaag

Een agent-harness is de software rond een taalmodel die het in staat stelt om echt werk te doen: commando's uitvoeren, bestanden bewerken, tools aanroepen. Claude Code van Anthropic is daar een bekend voorbeeld van. Tot nu toe keek zo'n harness vooral naar de machine. De gebruiker geeft een opdracht, en de harness vertaalt die naar handelingen op de computer. Latent Space beschrijft hoe Claude Mods die richting omdraaien. In een eerder stuk betoogde het blad al dat modellen steeds meer van de harness in hun eigen gewichten opnemen: wat vroeger met losse instructies en hulpmiddelen moest, kan het model steeds vaker zelf. Wat overblijft, is het deel dat naar de mens kijkt. Latent Space noemt dat de 'Attention Interface': de laag die beslist wanneer de agent je onderbreekt, wat hij je laat zien en welke beslissingen hij jou voorlegt.

🔬 Hoe een mod ingrijpt
Van gebeurtenis in Claude Code tot aangepaste weergave
Gebeurtenis

Claude Code meldt een gebeurtenis: een prompt, een toolcall of een schermweergave.

Mods zijn plug-ins met TypeScript- of JavaScript-functies die binnen Claude Code draaien, zowel in de terminal als in de desktopapp. Ze worden actief op gebeurtenissen in de werkstroom.

Observeren

De mod ziet de gebeurtenis en kan daarop reageren.

Een mod kan bijvoorbeeld bijhouden welke tools de agent gebruikt of hoe lang een taak loopt, en dat in een paneel of statusregel tonen die de gebruiker zelf heeft ontworpen.

Aanpassen

De mod verandert hoe de gebeurtenis op het scherm verschijnt.

Panelen, statusregels en meldingen worden zo afgestemd op de manier waarop iemand wil opletten. Latent Space noemt mods daarom middleware voor de harness.

Afhandelen

De mod kan de gebeurtenis zelf afhandelen, in plaats van het standaardgedrag.

Daarmee verandert de mod niet alleen het uiterlijk, maar ook de uitvoering van Claude Code tijdens het draaien. Mens en agent bouwen zo samen het menselijke deel van de harness.

Middleware voor menselijke aandacht

Technisch is een mod een plug-in voor Claude Code, opgebouwd uit TypeScript- of JavaScript-functies die binnen de applicatie draaien, in de terminal en in de desktopversie. Mods reageren op gebeurtenissen, zoals een prompt, een toolcall of het tekenen van de interface. Ze kunnen die gebeurtenis bekijken, aanpassen hoe ze wordt weergegeven, of haar helemaal zelf afhandelen in plaats van het standaardgedrag. Latent Space noemt dat middleware voor de agent-harness: code die tijdens het draaien de uitvoerings- en weergavestroom verandert. Het opvallendste is wie die code schrijft. Omdat Claude zelf kan programmeren, kan de gebruiker samen met de agent ontwerpen hoe die agent met hem samenwerkt. De auteur beschrijft hoe hij Claude Code zo wekenlang naar zijn eigen werkwijze heeft gekneed. Dat raakt een reëel probleem: wie meerdere agents tegelijk laat werken, verliest snel het overzicht.

De harness als volgende platform

Latent Space trekt een gewaagde vergelijking. Zoals de browser een platform werd voor webapps, zou de harness een platform kunnen worden voor de interfaces tussen mensen en agents, met de modellen als motor. In die visie concurreren AI-bedrijven straks niet alleen op de slimheid van hun model, maar op de omgeving waarin anderen bouwen. Dat verklaart waarom de stap strategisch is voor Anthropic: een harness waarop derden uitbreidingen maken, bindt gebruikers sterker dan een model dat morgen door een concurrent kan worden ingehaald. Het verwante bericht in deze krant over Starling, een Linux-desktop die grotendeels door AI is geschreven en nu een eigen kantoorpakket krijgt, laat de andere kant van dezelfde beweging zien: AI schrijft niet alleen code binnen applicaties, maar ook de omgeving eromheen. Tegelijk brengt programmeerbaarheid risico's mee, want code die toolcalls kan onderscheppen, moet even kritisch worden bekeken als elke andere plug-in.

Uiteindelijk wordt de harness een platform waarop andere bedrijven bouwen, met modellen als de motor.

— Latent Space, over Claude Mods (vertaald)

Conclusie

De werkelijke schaarste in het werken met agents is niet langer rekenkracht of modelkwaliteit, maar menselijke aandacht. Claude Mods nemen dat serieus door de gebruiker zelf te laten bepalen wanneer en hoe een agent hem stoort. Of de harness werkelijk het nieuwe browserplatform wordt, is nog speculatief; de vergelijking komt uit één, duidelijk enthousiaste bron. Maar de richting klopt: wie de interface tussen mens en agent beheert, beheert de relatie met de gebruiker. Dat Anthropic die laag openzet voor aanpassing, in plaats van haar dicht te timmeren, is een opvallende keuze. Het maakt elke gebruiker tot mede-ontwerper, en elke goede mod tot een reden om te blijven.
