Tech-insider.org publiceert een stappenplan: een eigen MCP-server in 13 stappen en 90 minuten.

Het Model Context Protocol koppelt AI-apps zoals Claude Desktop aan eigen data en tools.

Het protocol is in twee jaar uitgegroeid tot gedeelde standaard in de AI-sector.

Een eigen server bouwen is laagdrempelig, veilig beheren is de echte uitdaging.

Een stekkerdoos voor AI

Tech-insider.org heeft een stappenplan gepubliceerd waarmee beginnende ontwikkelaars in 13 stappen en ongeveer 90 minuten een eigen MCP-server bouwen. Het artikel zelf lag niet voor bij het schrijven van deze achtergrond, dus de afzonderlijke stappen blijven hier buiten beschouwing; dit stuk legt uit waarom zo'n handleiding er nu toe doet. Het Model Context Protocol werd in november 2024 door Anthropic geïntroduceerd als open standaard om AI-assistenten te koppelen aan externe data en gereedschap. Het idee wordt vaak vergeleken met een USB-aansluiting: in plaats van voor elke combinatie van AI-app en databron een eigen koppeling te bouwen, spreken beide kanten één protocol. Een MCP-server biedt functies aan, de AI-app gebruikt ze. Wie een eigen server bouwt, kan Claude Desktop bijvoorbeeld toegang geven tot een eigen database, notities of interne systemen.

Van Anthropic-experiment naar sectorstandaard

Dat een handleiding voor beginners de moeite waard is, zegt iets over hoe snel MCP zich heeft verspreid. Wat begon als Anthropic-initiatief werd in 2025 ook door OpenAI omarmd, en eind dat jaar bracht Anthropic het protocol onder bij een stichting onder de vleugels van de Linux Foundation. Daarmee is het geen bedrijfseigen techniek meer maar gedeelde infrastructuur. Er zijn officiële bibliotheken voor onder meer Python en TypeScript, waardoor een eenvoudige server met een paar tools in weinig regels code te schrijven is. Negentig minuten is dan geen overdreven belofte. Tegelijk verschuift de moeilijkheid. Het bouwen is simpel geworden; het lastige zit in goede toolbeschrijvingen, foutafhandeling en vooral beveiliging. Een server die een AI toegang geeft tot bestanden of systemen, is ook een mogelijke ingang voor misbruik, bijvoorbeeld via kwaadaardige instructies in de data die het model leest.

Een MCP-server bouwen kost een middag. Bepalen wat je een AI-model veilig laat doen, kost meer nadenken dan dat.

Wat het betekent voor gebruikers

De handleiding past in een reeks verhalen in deze krant over gewone gebruikers die Claude Desktop ver voorbij de chatfunctie oprekken. Een zestigjarige bouwt met geneste sessies een team van AI-agents, een 74-jarige laat Claude zeven open-sourceprogramma's installeren en bedienen. MCP is de techniek die zulke koppelingen structureel maakt: niet elke keer een eenmalige truc, maar een herbruikbare aansluiting. Voor bedrijven en Europese organisaties is dat aantrekkelijk, omdat ze eigen data kunnen ontsluiten zonder alles naar een cloudplatform te verhuizen; een lokale server houdt de data op de eigen machine. De keerzijde is dat elke zelfgebouwde koppeling ook zelf onderhouden en beveiligd moet worden.

Conclusie

Het succes van MCP valt af te meten aan dit soort stappenplannen: wat twee jaar geleden een specificatie voor specialisten was, is nu een middagproject voor beginners. Dat verlaagt de drempel, maar verlegt ook de verantwoordelijkheid naar de bouwer. Wie de 13 stappen volgt, doet er goed aan een veertiende toe te voegen: nadenken over wat de server precies mag.
