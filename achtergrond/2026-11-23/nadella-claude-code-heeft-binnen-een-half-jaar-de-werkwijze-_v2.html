Een opvallende erkenning

Microsoft-topman Satya Nadella zegt dat Claude Code van Anthropic in ongeveer een half jaar de werkwijze van ontwikkelaars heeft veranderd, meldt ETtoday op basis van berichtgeving van Windows Latest van 23 november. Sommige ontwikkelaars hebben maandenlang VS Code niet geopend, en Nadella zegt dat hij dat volledig begrijpt. Dat is opmerkelijk: Microsoft werkte meer dan tien jaar om VS Code tot standaardplatform voor ontwikkelaars te maken, en Anthropic is een partner die tegelijk concurreert. Nadella gaf zijn eigen product ook krediet: de open ontwikkelwijze en het dagelijks lezen van gebruikersfeedback door productmanagers bouwden een grote gemeenschap.

Van typen naar beschrijven

De kern van Nadella's analyse is een verschuiving in wat ontwikkelen is. Anthropic boekte niet alleen vooruitgang in modelkwaliteit, maar kreeg ontwikkelaars ook zover het werk via de opdrachtregel aan een AI te geven. Waar je vroeger code zelf typte, beschrijf je nu wat je wilt en laat je een agent het uitvoeren. Zijn les is dat bedrijven niet te gehecht moeten raken aan hun eigen product, ook niet als het succesvol was. Hij ziet de IDE niet als verloren: met de volgende generatie modellen kan het centrale werk in een IDE verschuiven naar het schrijven van volledige Markdown-documenten die eisen, functies en uitvoering vastleggen, waarna AI de bouw doet.

Bedrijven moeten niet te veel gehecht raken aan het product dat ze zelf hebben gebouwd, ook als het succesvol was.
De reactie van Microsoft en de markt

De recente releases tonen hoe Microsoft de koers bijstuurt. Versie 1.146 van 11 november bracht een AI-agentinbox en modelvergelijking; 1.147 van 18 november voegde modelrouting toe, waarmee per taak het passende model uit de voorkeuren van de gebruiker wordt gekozen, plus gepland indienen van agentverzoeken en browserintegratie. Zo probeert VS Code te veranderen van editor in controlepaneel voor agents. De vraag is of dat voldoende is. Claude Code is zo gewild dat er volgens een Russischtalige bron een grijze markt is ontstaan voor toegang vanuit Rusland, waar betaalpogingen via virtuele kaarten en VPN vaak eindigen in een permanente accountban. Een ander perspectief dus: de vraag naar Claude Code is groter dan het officiële aanbod bedient.

Conclusie

Nadella's uitspraak is minder een nederlaag dan een koerswijziging, maar wel een eerlijke. De waarde in softwareontwikkeling verschuift van de editor naar het model en de agent eromheen. Microsoft heeft nog een sterke positie in distributie en samenwerking, maar de standaardplek van de editor is niet langer vanzelfsprekend. De winnaar is wie de beste opdracht-naar-resultaat-keten bouwt.
