Claude Code krijgt Code Mode: Claude schrijft JavaScript dat meerdere tools in één keer aanstuurt.

Normaal roept Claude tools als Bash, Read en Edit één voor één aan.

Het script draait in de sessie en combineert tools zonder tussentijds overleg per stap.

Dat bespaart rondes en context, maar vraagt om vertrouwen in gegenereerde code.

Van stap voor stap naar programmeren

Claude Code heeft een nieuwe functie, Code Mode, meldt het Japanse xenospectrum. Normaal roept Claude tools als Bash, Read en Edit één voor één aan en beslist het na elk resultaat over de volgende stap. In Code Mode genereert Claude op basis van de opdracht JavaScript dat Claude Code in de sessie uitvoert, waarmee meerdere tools in één keer worden gecombineerd. Het is een kleine architectuurwijziging met grote implicaties: het model schrijft niet langer alleen code voor een gebruiker, maar gebruikt code als zijn eigen werkwijze. Voor dit stuk is geen verdere bronnentekst beschikbaar, dus detailvragen over beperkingen en veiligheidsmaatregelen blijven open.

Waarom dit logisch is

Het idee past in een bredere trend: agents worden efficiënter als ze logica in code kunnen vatten. Een lus over honderd bestanden is in code één regel; als losse tool-aanroepen zijn het honderd rondes, elk met tokens, wachttijd en kans op afdwalen. Door tussenresultaten in het script te houden in plaats van in het gesprek, blijft bovendien de context schoon, wat bij lange sessies een knelpunt is. Dat maakt Code Mode vooral aantrekkelijk voor repetitieve, grootschalige taken zoals refactors over een volledige codebase. De prijs is controleerbaarheid: wie elke stap ziet, kan elke stap goedkeuren, terwijl een script als geheel moet worden vertrouwd of vooraf nagelezen.

Perspectieven en context

De vraag is hoe gebruikers en bedrijven dit ontvangen. Ontwikkelaars die al veel met Claude Code werken, zullen de snelheidswinst waarderen; wie zorg heeft over wijzigingen aan een productiecodebase, zal willen weten hoe rechten en goedkeuringen werken als een script meerdere tools tegelijk aanstuurt. Dat het ecosysteem rond Claude Code volwassen wordt, blijkt uit ander nieuws in dezelfde krant: een Japanse scholingsfirma bouwt een site voor 80 procent met Claude Code en is toegelaten tot Claude Startups, terwijl een hoofdontwikkelaar van de desktopapp, Anthony Morris, in oktober naar OpenAI is vertrokken. Het toont hoe sterk de concurrentie om ontwikkelaars en talent is.

Conclusie

Code Mode is geen revolutie maar een slimme verschuiving: het model gebruikt de taal waarin het sterk is, code, om zijn eigen gereedschap te bedienen. De winst in snelheid en context is aannemelijk; de werkelijke toets is of de beveiligings- en goedkeuringsmechanismen meegroeien. Wie agents wil laten werken met meer autonomie, moet de controle mee ontwerpen, niet achteraf toevoegen.
